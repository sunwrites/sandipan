# Cat Project

A simple HTML project showcasing a cute cat photo.

## Summary

This project is a basic web page that displays a centered card layout with a cat image and a short description. It demonstrates a simple HTML and CSS design using a clean, responsive structure.

## Features

- Responsive design
- Clean and simple layout
- Cat photo from Unsplash

## Files

- `index.html` - Main HTML file
- `styles.css` - Stylesheet for page design

## Live View

Open `index.html` in your browser to view the cat project.
